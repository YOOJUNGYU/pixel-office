Pixel Office

AI 코딩 에이전트가 픽셀 사무실의 캐릭터가 되어 일하는 모습을 보여 주는 앱입니다.

혼자 써도 되고, 팀이나 다른 사람들과 같이 봐도 됩니다.

내 PC에서 돌고 있는 Claude Code와 Codex 세션을 읽어서, 에이전트 하나하나를 사무실 캐릭터로 보여 줍니다. 파일을 고치면 코딩실, 뭔가 찾아보면 자료실, 명령을 돌리면 서버실로 걸어가 앉고, 머리 위 말풍선과 PC 화면을 보면 지금 무슨 일을 하는지 알 수 있습니다. 사무실은 누구나 들어오는 공개 오피스, 방장이 만든 방에 입장하는 팀 오피스, 나 혼자 쓰는 개인용 중에서 고르면 됩니다. 대기실 게임기에 앉으면 잠깐 게임도 할 수 있고(기록은 명예의 전당에 남습니다), 📊 버튼을 누르면 토큰을 얼마나 썼는지 볼 수 있고, 토큰을 많이 쓴 에이전트는 몸집이 커지고 빨리 쓰는 에이전트는 몸에 불꽃이 붙습니다. 그 밖에 옷장으로 꾸미는 사람 캐릭터와 상태 메시지, 세션 대화를 통째로 보는 창, 지난 세션 찾기와 대화 내용 검색, 응답을 기다리거나 일이 끝났을 때 오는 알림, 레이아웃 편집이 있고, Windows·Mac 설치 파일로 깔면 알아서 업데이트됩니다.

원작과 다른 점 설치 사용법 보안과 개인정보 동작 방식 알려진 한계 개발 크레딧 라이선스

원작과 다른 점

pixel-agents(MIT)를 가져와 고친 프로젝트입니다. 원작은 VS Code 확장이라 VS Code 안에서 Claude Code를 실행하고, 내 PC의 에이전트만 캐릭터로 보여 줍니다. 사무실을 그리는 엔진, 레이아웃 편집기, 가구 그림은 원작 것을 그대로 씁니다.

토큰 사용량 기능은 token-dashboard를 참고했습니다. 대화 기록을 읽어 날짜·프로젝트·모델별로 집계하고 비싼 세션을 뽑아 보여 주는 아이디어와, 같은 응답이 여러 줄로 남을 때 한 번만 세는 방식을 가져왔습니다. 코드는 가져오지 않고 새로 짰고, 따로 띄우는 대시보드 대신 사무실 안 패널로 넣었습니다. Codex 집계, 캐릭터 크기와 불꽃, 끝난 세션의 대화 열기는 여기서 더한 것입니다.

설치

  1. Releases에서 내 OS에 맞는 파일을 받습니다. Windows는 PixelOffice-<버전>-Windows.exe, Mac은 PixelOffice-<버전>-Mac.pkg입니다(Apple 칩, Intel 둘 다 됨). Node가 들어 있어서 따로 깔 건 없습니다.
  2. 코드 서명을 안 해서 설치할 때 경고가 뜹니다.
    • Windows: "Windows의 PC 보호" 창에서 추가 정보 → 실행을 누르고, 사용자 계정 컨트롤에서 예.
    • Mac: "열지 않음" 창이 뜨면 휴지통 말고 완료를 누르세요. 그다음 시스템 설정 → 개인정보 보호 및 보안에서 그래도 열기를 누르고 pkg를 다시 엽니다. 터미널이 편하면 sudo installer -pkg <받은 pkg> -target /. 방화벽이 켜져 있으면 들어오는 연결을 허용해 주세요.
  3. 설치가 끝나면 브라우저에 사무실이 열립니다. 캐릭터와 색을 고르면(닉네임은 안 정해도 됨) 사용법 안내가 이어서 나옵니다.

로그인하면 자동으로 켜집니다. 이건 설정 → 로그인할 때 자동 실행에서 끌 수 있습니다. 앱을 끄려면 트레이 아이콘에서 Pixel Office 종료를 누르거나 설정 → 완전 종료를 누르세요. 다시 열 때는 트레이, 바탕화면이나 시작 메뉴 바로가기, Mac의 응용 프로그램 폴더, 아니면 그냥 http://localhost:47801로 들어가면 됩니다.

다른 PC가 안 보이거나 지우는 방법이 궁금하면 설치 안내를 보세요. 회사 보안 프로그램이 막는다면 IT 담당자에게 예외 등록을 부탁해야 합니다.

사용법

방마다 하는 일이 다릅니다

에이전트는 같은 종류의 일을 3초쯤 계속하면 그 방으로 걸어가서 빈자리에 앉습니다. 잠깐씩 바뀌는 일 때문에 왔다 갔다 하지 않게 하려고 이렇게 했습니다.

방언제 가나
🖥️ 코딩실파일을 고칠 때 (Claude Edit/Write, Codex apply_patch, sed -i·> 파일 같은 명령으로 고칠 때)
📚 자료실파일을 읽거나 코드·웹을 검색할 때 (Codex의 rg, cat, git log 같은 명령 포함)
🗄️ 서버실명령을 실행할 때, 백그라운드 셸
🛋️ 대기실질문에 답을 기다릴 때, 서브에이전트에 일을 맡겼을 때, 일을 마쳤을 때 (명령 승인은 일하던 방에서 기다립니다)

서버실은 바닥 테이프로 네 구역이 나뉘어 있어서 명령 종류에 맞는 구역에 앉습니다. 왼쪽 위는 테스트(vitest, pytest, npm test, curl 등), 오른쪽 위는 빌드(tsc, lint, 패키지 설치, docker 등), 왼쪽 아래는 Git, 오른쪽 아래는 나머지 명령입니다. 구역이 꽉 차면 서버실 안의 다른 빈자리로 갑니다.

대기실은 사람 자리라서, 여기로 돌아온 에이전트는 따로 보이지 않고 그 PC 주인의 사람 캐릭터에 합쳐집니다.

방 이름표에 마우스를 올리면 어떤 일로 그 방에 오는지와 지금 그 방에 있는 에이전트들이 보입니다. 이름표 옆 에이전트 3 같은 숫자는 서브에이전트와 셸까지 센 겁니다.

캐릭터 읽는 법

캐릭터 아래에는 이름표가 있습니다. MAIN은 메인 에이전트, SUB는 서브에이전트, SHELL은 백그라운드 셸이고, 그 뒤에 #번호와 주인 이름이 붙습니다. 서브에이전트와 셸은 부모 번호를 따라갑니다.

일하는 에이전트 머리 위에는 말풍선이 뜹니다. 맨 윗줄에 Claude인지 Codex인지(내 에이전트와 같은 망 사람 에이전트는 모델 이름), 무슨 일을 하는지 아이콘, 세션 제목, 할 일 진행(3/7), 지금 일을 시작하고 몇 분 지났는지가 나오고, 그 아래에 하는 일이 적혀 있습니다. 오래 걸리면 시간이 주황색으로 바뀝니다. 마우스를 올리면 전체 내용이 다 보입니다. 머리 위에 빨간 !가 뜨면 승인이나 답을 기다리는 중입니다. 내 에이전트는 캐릭터나 말풍선을 누르면 대화 창이 열립니다. 다른 사람 에이전트의 말풍선이 많아 어지러우면 왼쪽 위 💬 버튼으로 숨길 수 있습니다(내 것은 그대로 보이고, 마우스를 올리면 보입니다).

그 밖에 이런 것들도 보입니다.

  • 에이전트가 앉은 PC 화면이 하는 일에 따라 바뀝니다. 코드를 고치면 초록 코드, 명령을 돌리면 검은 터미널, 뭔가 읽으면 흰 문서 화면입니다.
  • 파일을 고치면 머리 위로 +12 −3처럼 바꾼 줄 수가 떠오릅니다.
  • 도구가 실패하면 PC가 빨갛게 깜빡이고 연기가 납니다.
  • 할 일을 다 끝내거나 일을 마치면 폭죽이 터집니다.
  • 서버실에서 명령이 돌고 있으면 서버 PC의 LED가 깜빡입니다.
  • 이름표 끝에는 컨텍스트를 얼마나 썼는지(29%)가 붙습니다.
  • 내 메인 에이전트가 답을 기다리는 동안에는 Claude 프롬프트 캐시가 얼마나 남았는지(❄ 4:23)가 붙습니다. 0이 되기 전에 답하면 캐시를 다시 쓰지 않아도 됩니다.
  • 옷장으로 꾸민 캐릭터는 가끔 눈을 깜빡입니다.
  • 화면을 많이 축소하면 말풍선 대신 아이콘만 보입니다.

서브에이전트와 셸은 부모와 같은 방에 있으면 부모 옆 빈자리에 앉습니다. 부모가 서브에이전트에게 일을 맡기거나 서브에이전트가 결과를 보고할 때는 둘이 마주 보고 잠깐 이야기를 나눕니다.

지도는 드래그로 옮기고 휠로 확대·축소합니다. 왼쪽 위 + / − 버튼도 있고, 네 모서리 버튼(화면 맞춤)을 누르면 사무실 전체가 창에 꼭 맞게 돌아옵니다. 왼쪽 위 버튼에 마우스를 올리면 바로 아래에 무슨 버튼인지 이름이 뜹니다.

상태별 모습

아래는 모두 가상 데이터로 찍은 화면입니다. 크기, 불꽃, 토큰 수, 모델 배지, 컨텍스트는 같은 망 사람에게도 보입니다. 📦와 캐시 남은 시간은 내 에이전트에만 보입니다.

화면상태설명
토큰을 많이, 빨리 쓰는 중이 세션에서 100만 토큰 넘게 써서 2배 크기가 됐고, 1분에 7만 5천 토큰 넘게 쓰고 있어서 빨간 불꽃이 붙었습니다. 이름표 끝 1.4M · Σ1.9M은 이 세션이 쓴 토큰과 서브에이전트까지 합친 토큰입니다. 보라색 배지는 Opus 모델이라는 뜻입니다.
꽤 빨리 쓰는 중30만 토큰을 넘어서 1.5배, 1분에 4만 토큰 넘게 써서 노란 불꽃이 낮게 붙었습니다. 이 캐릭터는 서브에이전트이고, 파란 배지는 Sonnet입니다.
꾸준히 쓰는 중1분에 1만 5천 토큰을 넘으면 파란 테두리가 생깁니다. 서버실 테스트 구역에서 명령을 돌리고 있어서 PC 화면이 터미널입니다.
가볍게 일하는 중토큰을 많이 안 썼으면 원래 크기에 테두리도 없습니다. 초록 배지는 Haiku이고, 파일을 읽는 중이라 PC에 문서 화면이 떠 있습니다.
CodexCodex 세션은 초록색 Codex 배지가 붙습니다. 지금은 서버실 Git 구역에 있습니다.
답 기다리는 중질문에 답을 기다리는 에이전트는 대기실에서 내 사람 캐릭터에 합쳐지고, 사람 머리 위에 빨간 !가 뜹니다. 명령 승인을 기다릴 때는 일하던 방에서 에이전트 머리 위에 뜹니다.
파일 수정바꾼 줄 수가 +24 −6처럼 떠오릅니다.
결과가 크거나 실패도구 결과가 5만 토큰을 넘으면 📦 +82k가 떠오릅니다. 도구가 실패하면 PC가 빨갛게 깜빡이고 연기가 나며, 머리 옆에 물방울이 맺힙니다.
할 일 완료할 일 목록을 다 끝내거나 메인 에이전트가 일을 마치면 폭죽이 터집니다.
마우스를 올렸을 때하는 일 전체와 방, 이유, 걸린 시간, 할 일, 바꾼 줄 수, 컨텍스트, 토큰, 모델, 분당 사용량이 한꺼번에 보입니다.

크기와 불꽃의 기준은 이렇습니다.

  • 크기는 그 세션이 지금까지 쓴 토큰으로 정합니다. 30만이 넘으면 1.5배, 100만이 넘으면 2배입니다. 픽셀이 뭉개지지 않게 세 단계만 둡니다.
  • 불꽃은 최근 2분 동안 1분에 쓴 토큰으로 정합니다. 1만 5천이 넘으면 파란 테두리, 4만이 넘으면 노란 불꽃, 7만 5천이 넘으면 빨간 불꽃입니다.
  • 여기서 토큰은 입력, 출력, 캐시 쓰기를 더한 값입니다. 캐시 읽기는 양이 워낙 커서 빼고, 사용량 패널에서 따로 보여 줍니다.

같은 망 사람의 에이전트도 크기와 불꽃, 토큰 수, 모델, 컨텍스트, 세션 제목, 할 일 진행, 걸린 시간, 바꾼 줄 수가 똑같이 보이고, 앉은 자리도 모든 PC에서 같습니다. 공개 오피스에서는 무슨 파일을 고치는지, 어떤 명령을 돌리는지는 빼고 “파일 수정 중” 같은 일의 종류만 보이고, 팀 오피스에서는 프로그램 이름과 파일 이름까지 보입니다. 기준값 근처에서 불꽃이 자꾸 바뀌지 않게, 한 번 올라간 불꽃은 30초 동안 유지됩니다. 1.0.64 이하 PC에는 이 중 크기와 불꽃만 보입니다.

토큰 사용량 (📊)

token-dashboard에서 아이디어를 얻은 기능입니다. 왼쪽 위 📊 버튼을 누르면 버튼 바로 아래에 사용량 패널이 열립니다. 오른쪽 끝, 아래 끝, 오른쪽 아래 모서리를 잡아 끌면 크기를 바꿀 수 있고, 바꾼 크기는 기억해 둡니다. 다시 누르거나 ×를 누르면 닫힙니다.

위쪽 "지금"에는 오늘 자정부터 쓴 토큰과, 지금 일하고 있는 내 에이전트별 토큰·모델·분당 사용량이 나옵니다. 줄을 누르면 그 세션의 대화 창이 열립니다. Codex를 쓰면 그 아래 "Codex 한도"에 5시간·주간 한도를 몇 % 썼는지, 남은 시간에 비해 빨리 쓰고 있는지, 이 속도면 언제 한도에 닿는지가 나옵니다(Claude는 대화 기록에 한도를 남기지 않아서 보여 줄 수 없습니다).

아래쪽 기록은 7일, 30일, 전체 중에서 고릅니다. 날짜별 막대 그래프, 캐시 읽기, 프로젝트별 순위, 모델별 비중, 그리고 토큰을 가장 많이 쓴 세션 10개가 나옵니다. 이미 끝난 세션도 누르면 대화를 볼 수 있습니다. 기록 파일이 지워진 세션은 흐리게 표시됩니다.

패널 위 세션 탭에는 지난 세션이 최신순으로 나옵니다. 세션마다 실제로 일한 시간(줄 사이가 5분 넘게 비면 빼고 셉니다), 도구를 쓴 횟수, 파일을 고친 횟수가 붙습니다. 검색창에 쓰면 제목과 폴더로 찾고, 대화 내용까지를 켜면 프롬프트와 답변에서 찾아 일치한 부분을 한 줄 보여 줍니다(최신 세션부터 30개까지, 32MB가 넘는 기록은 건너뜁니다). 검색 결과를 누르면 대화 창이 그 자리에서 열리고, 일치한 곳에 테두리가 쳐지며 ↑ / ↓로 오갈 수 있습니다.

집계는 이렇게 합니다.

  • Claude Code와 Codex 대화 기록을 모두 읽어서(WSL 포함) 숫자만 ~/.pixel-office/usage.json에 모아 둡니다. 프롬프트 내용은 저장하지 않습니다.
  • Claude Code가 오래된 기록을 지워도 모아 둔 숫자는 남습니다.
  • 처음 켤 때 한 번 전부 읽고("기록 스캔 중…"), 그 뒤로는 새로 늘어난 부분만 읽습니다.
  • 같은 응답이 기록에 여러 줄로 남아도 한 번만 셉니다. 금액으로 바꿔 보여 주지는 않습니다.
  • 이 패널과 세션 목록, 검색은 이 PC에서만 보이고 다른 PC로는 보내지 않습니다.

오피스 고르기

화면 맨 위 버튼(🏠 개인용, 🌐 공개 오피스, 🔒 팀 순서)으로 언제든 바꿀 수 있습니다. 처음 설치하면 개인용으로 시작하고, 그 뒤로는 마지막에 고른 오피스로 열립니다.

🌐 공개 오피스는 같은 망(LAN)에서 앱을 쓰는 사람이면 누구나 따로 설정 없이 함께 들어오는 사무실입니다. 에이전트, 사람 캐릭터, 상태 메시지, 배치는 같은 망 안에서만 오갑니다.

다른 망(집, 다른 사무실, 카페)에서 앱을 쓰는 사람은 사무실에는 나타나지 않고 오른쪽 접속자 목록에만 나옵니다. Cloudflare 중계가 지금 누가 접속해 있는지만 알려 줍니다. 목록은 같은 망 사람끼리 묶여 있고 나와 같은 망이 맨 위에 옵니다. 망이 둘 이상이면 이름 옆에 망 1(내 망), 망 2 같은 배지가 붙습니다. 사람이 많으면 처음 10명만 그리고, 스크롤을 내리면 더 불러옵니다.

공개 오피스의 같은 망 사람에게는 계정 이름, 닉네임, 캐릭터, 상태 메시지, 에이전트가 어느 방 어느 자리에 있는지, 세션 제목, 모델, 토큰 수, 컨텍스트, 할 일 진행, 걸린 시간, 바꾼 줄 수가 보입니다. 에이전트가 무슨 파일을 고치는지, 어떤 명령을 돌리는지, 답변 내용 같은 작업 내용은 보이지 않습니다.

중계는 동시에 1,000명까지 받습니다. 중계가 꽉 찼거나 하루 사용량을 다 썼거나 인터넷이 막혀 있으면 접속자 목록의 "공개 오피스" 제목 옆에 이유가 뜹니다(잘 연결돼 있을 때는 아무것도 안 뜹니다). 그래도 같은 망 사람들은 계속 보이고, 문제가 풀리면 알아서 다시 연결합니다.

🔒 팀 오피스는 같은 망에서 방에 들어온 사람끼리만 씁니다. 인터넷으로는 나가지 않고 중계에도 연결하지 않습니다. 왼쪽 위 🚪 방 버튼의 새 방 만들기에 방 제목, 접속코드(선택), 최대 인원을 적어 만들면 내가 방장이 되고, 같은 망 사람들의 방 목록에 그 방이 뜹니다. 목록에서 입장을 누르면 들어가고, 🔒 방은 접속코드를 물어봅니다. 접속코드 없이 만든 방은 같은 망 누구나 들어올 수 있습니다. 방장 PC가 켜져 그 방을 보고 있어야 새로 들어올 수 있고, 한 방에 최대 20명(방장이 2~20명으로 정함)입니다. 방장은 🚪 패널에서 제목·최대 인원·코드를 바꾸고 멤버를 강퇴할 수 있습니다. 강퇴된 사람은 개인용으로 옮겨지고, 코드 없는 방에는 다시 들어올 수 없으며 코드 있는 방에는 코드로 다시 들어올 수 있습니다. 방장이 나가거나(나가기, 다른 방 만들기·입장, 개인용·공개 탭 전환 — 확인창이 뜹니다) 30초 동안 사라지면 먼저 들어온 다음 멤버가 방장을 이어받고, 돌아온 원래 방장은 멤버가 됩니다(1.0.80 이상 필요). 방은 한 번에 하나만 들어갈 수 있고, 다른 방을 만들거나 들어가면 물어본 뒤 바뀝니다. 나올 때는 🚪 패널의 나가기를 누릅니다. 팀 오피스에 들어가 있는 동안은 공개 오피스에서 내 모습이 사라진다는 점도 알아 두세요. 1.0.74 이하에서 초대 코드로 만든 팀은 그대로 동작하지만 방 목록에는 나오지 않습니다.

🏠 개인용은 나 혼자 쓰는 작은 사무실입니다. 에이전트, 상태 메시지, 캐릭터 위치가 다른 PC로 나가지 않고, 다른 사람 접속자 목록의 "개인용"에 이름만 보입니다(다른 망 사람에게는 중계를 거쳐). 팀에서 나가는 게 아니라서 나중에 코드 없이 팀으로 돌아갈 수 있습니다.

내 캐릭터와 상태 메시지

에이전트와 따로, 사람마다 캐릭터가 하나씩 있습니다. 방향키로 어느 방이든 걸어 다닐 수 있고, 대기실 의자에는 앉을 수도 있습니다. 위치는 앱을 다시 켜도 그대로입니다.

설정 → 내 프로필 → 옷장에서 꾸미기를 누르면 몸, 눈, 머리, 상의, 겉옷, 하의, 신발, 원피스, 모자와 수염·안경 같은 장신구를 하나씩 고르고 색을 바꿀 수 있습니다(pixel-agents의 옷장을 가져왔습니다). 꾸민 모습은 내 사람 캐릭터와 내 에이전트 모두에 쓰이고 다른 PC에도 그대로 보입니다. 1.0.63 이하 PC에는 원래 고른 기본 캐릭터로 보입니다.

화면 아래 가운데 입력창에 지금 상태("🍜 점심 먹는 중" 같은)를 쓰고 Enter를 누르면 내 캐릭터 머리 위에 한 줄로 걸립니다. 길면 …로 줄고, 마우스를 올리면 전부 보입니다. 입력창에는 지금 상태가 들어 있어서 그 자리에서 고치면 되고, 비우고 Enter를 누르거나 ×를 누르면 지워집니다. 기록은 남지 않고 알림도 가지 않습니다. 100자까지, 2초에 한 번 바꿀 수 있습니다. 아무것도 선택하지 않은 상태에서 Space+Enter를 누르면 입력창으로 가고, Esc를 누르면 다시 방향키로 캐릭터를 움직일 수 있습니다.

오락실

대기실 윗벽에 게임기 여섯 대가 가운데 문 양쪽에 세 대씩 있습니다. 게임기 앞 의자에 앉으면 그 게임이 바로 시작되고, 왼쪽에 게임 방법, 오른쪽에 명예의 전당이 나옵니다. Esc로 그만두고 방향키로 일어나면 됩니다.

방화벽 깨기패들로 공을 튕겨 블록을 깹니다. 단단한 블록, 강철, 아이템 캡슐
케이블케이블을 몰아 패킷을 먹고 길어집니다. 금색 버스트, 방화벽
버그 잡기9대 모니터에 뜨는 버그를 잡습니다. 초록 패치는 잡으면 감점, 45초
드론 배송Space로 날갯짓해 서버랙 사이 틈을 지납니다
머지방향키로 밀어 같은 숫자끼리 합칩니다
랙 쌓기Space로 움직이는 서버 유닛을 떨어뜨려 높이 쌓습니다
  • 게임기 하나에 한 명씩입니다. 누가 앉아 있으면 "○○님이 하는 중" 안내가 뜨고, 자리가 비면 앉을 수 있습니다.
  • 명예의 전당에는 게임마다 사람별 최고 점수가 상위 50명까지 남고, 접속하지 않은 사람 기록도 남습니다. 지금 접속 중인 사람은 ●로 표시됩니다.
  • 점수는 조작할 수 없게 중계 서버가 직접 계산합니다. PC는 점수 대신 입력 기록을 보내고, 중계 서버가 같은 게임을 다시 돌려 점수를 매깁니다.
  • 인터넷이 안 되면 게임은 할 수 있지만 기록되지 않습니다. M 키나 🔊 버튼으로 소리를 끌 수 있습니다.

세션 대화 보기

내 에이전트 캐릭터나 그 말풍선을 누르면 그 세션의 대화 전체가 새 창으로 열립니다. 질문, 답변, 도구 호출, 결과까지 다 나옵니다. 대기실에 합쳐진 에이전트는 내 사람 캐릭터를 누르면 목록이 나오니 거기서 고르면 됩니다. 셸을 누르면 그 명령의 출력이 보입니다.

창 위쪽에는 지금 상태와 컨텍스트 사용량(294k / 1M · 29%)이 있고, 그 아래 띠에는 최근 30분 동안 무슨 일을 했는지 1분 단위로 색칠돼 있습니다. 오른쪽 가장자리의 작은 지도는 대화 전체에서 프롬프트, 답변, 편집, 실패가 어디 있는지 보여 주고, 누르거나 끌면 그 자리로 갑니다. [내 프롬프트만]을 켜면 내가 쓴 프롬프트만 남고, Alt+↑ / Alt+↓로 내 프롬프트 사이를 건너뜁니다. 슬라이더로 글자 크기를 바꿀 수 있고, ×나 Esc로 닫습니다. 다른 사람의 에이전트는 열 수 없습니다.

접속자 목록과 알림

오른쪽 접속자 목록에는 이 오피스에 들어와 있는 사람이 에이전트가 있든 없든 다 나옵니다(공개 오피스는 다른 망 사람까지, 망별로 묶어서). 같은 망 사람 이름을 누르면 그 사람의 에이전트 쪽으로 화면이 따라갑니다. 이름 아래 줄에는 그 사람의 앱 버전이 나오고(아주 예전 버전은 “구버전”), 나와 다르면 경고색으로 표시됩니다.

앱 창을 닫아도 트레이가 떠 있으면 PC 알림이 옵니다. 설정에서 종류별로 끌 수 있습니다.

  • 공개 오피스에 누가 들어오거나 나갔을 때
  • 내 에이전트가 답을 기다리거나 일을 마쳤을 때. 서브에이전트나 셸이 끝났을 때는 알리지 않고, 메인 에이전트까지 완전히 끝났을 때만 알립니다.

그 밖에

  • 프로필: 캐릭터(사람 6종, 펫 Claudio와 Gitcat, 또는 옷장으로 꾸민 모습), 색, 닉네임, 이름표 색, 상태 메시지 색(배경·글자·테두리)을 고릅니다. 이름 앞에는 항상 PC 계정 이름이 붙고 이건 바꿀 수 없습니다. 닉네임이 다른 사람과 겹치면 나중에 정한 쪽 뒤에 · a1b2 같은 표시가 붙습니다.
  • 언어와 테마: 한국어/영어, 다크/라이트를 고릅니다. 왼쪽 위 해/달 버튼으로 바로 바꿀 수도 있습니다.
  • 레이아웃 편집: 왼쪽 위 레이아웃 버튼을 누르면 바닥, 벽 색, 가구, 바깥 배경을 바꿀 수 있습니다. 방 위치와 사무실 크기는 바꿀 수 없습니다. 책상, 의자, PC, 게임기는 사무실이 돌아가는 데 필요해서 고정이라 옮기거나 지울 수 없고 색만 바꿀 수 있습니다. 새 버전에서 기본 배치가 바뀌면 이 가구들은 저장해 둔 배치에도 알아서 반영됩니다. 고친 내용은 [저장]을 눌러야 반영되고, [취소]나 Esc를 누르면 전부 버려집니다. 공개 오피스와 팀 오피스에서는 저장하는 순간 같은 오피스 사람들 모두에게 바뀐 배치가 보이고, 여럿이 동시에 고치면 마지막에 저장한 사람 것이 남습니다. 개인용 배치는 내 PC에만 저장됩니다. 처음 배치로 돌리려면 [초기화] 후 [저장]을 누르세요.
  • 앱으로 설치: Edge나 Chrome에서 설치하면 탭이 아닌 별도 앱 창으로 열립니다. 서버가 꺼져 있을 때 앱을 열면 [시작] 버튼으로 켤 수 있습니다.
  • 자동 업데이트: 켤 때와 6시간마다 새 버전을 확인해서 조용히 받고 다시 시작합니다. 새 버전이 제대로 안 켜지면 이전 버전으로 돌아갑니다. 끌 수는 없습니다. 아주 가끔 Node 버전이 바뀌는 릴리스만 오른쪽 위에 업데이트 버튼이 떠서 설치 파일을 직접 받아야 합니다.
  • 사용 설명서: 왼쪽 위 ? 버튼을 누르면 모든 기능의 설명서가 버튼 아래에 열립니다. 왼쪽에서 기능을 고르면 오른쪽에 그 기능을 보여 주는 애니메이션과 설명이 나오고, 위쪽 검색창으로 찾을 수 있습니다(한국어·영어 어느 쪽으로 찾아도 됩니다). 사용량 패널처럼 오른쪽·아래 끝과 모서리를 끌어 크기를 바꿀 수 있고, [온보딩 시작]을 누르면 처음 안내를 다시 볼 수 있습니다.

보안과 개인정보

  • 다른 PC와는 화면에 보여 줄 상태만 주고받습니다. 남의 터미널이나 에이전트, 설정을 건드릴 방법은 없고, 화면은 내 PC 브라우저에서만 열립니다.
  • PC끼리 주고받는 내용은 모두 암호화합니다. 공개 오피스는 PC 두 대마다 X25519로 키를 맞춰 AES-256-GCM으로, 팀 오피스는 방장이 만든 무작위 비밀에서 유도한 키로 AES-256-GCM 암호화합니다. 방장은 들어오기를 허락한 사람에게만 그 비밀을 둘 사이 키로 봉인해 건네고, 입장할 때 적은 접속코드도 같은 식으로 봉인돼 방장 PC에만 갑니다. 방 목록에 뜨는 방 제목, 방장 이름, 잠김 여부, 인원 수는 같은 망에 암호화 없이 알려집니다. 한 번 본 PC의 키가 바뀌면 받아 주지 않아서 다른 PC인 척할 수 없습니다.
  • 인터넷 중계는 누가 접속해 있는지만 전합니다. 공개 오피스나 개인용을 쓰는 PC는 중계에 PC 식별자, 공개 키, 표시 이름(계정 이름과 닉네임), 캐릭터 모양, 앱 버전, 개인용인지를 보냅니다. 이 내용은 TLS로만 보호되고 중계에서는 읽을 수 있습니다. 에이전트, 상태 메시지, 배치는 중계로 가지 않습니다. IP 주소는 저장하지 않고, 같은 망끼리 묶어 보여 주려고 IP로 만든 해시만 씁니다. 다만 중계를 돌리는 Cloudflare는 접속 IP를 볼 수 있습니다. 팀 오피스는 중계에 연결하지 않습니다. 오락실 기록은 어느 오피스에서든 중계 서버에 PC 식별자와 표시 이름을 보내 저장합니다.
  • 파일 경로, 사용자 이름, IP, 호스트명, URL 경로, 토큰처럼 보이는 문자열, AI 답변 내용은 어떤 경우에도 PC 밖으로 나가지 않습니다. 명령은 프로그램 이름만 보냅니다. 세션 제목은 Claude가 붙인 제목, 직접 정한 제목, Codex 스레드 이름일 때만 같은 망으로 나가고(첫 프롬프트를 제목 대신 쓰는 경우는 보내지 않습니다), 그 안의 경로나 주소도 같은 규칙으로 가립니다. PC 계정 이름은 이름표에 쓰이니 항상 보입니다.
  • 공개 오피스(같은 망)에는 내 에이전트의 방과 자리, 종류, 일의 종류(편집·실행 같은), 답을 기다리는지, 세션 제목, 모델, 토큰 수, 컨텍스트, 할 일 개수, 걸린 시간, 바꾼 줄 수가 나갑니다. 팀 오피스에는 위 규칙을 지킨 선에서 작업 대상(프로그램 이름, 파일 이름 등)까지 나갑니다.
  • Claude Code와 Codex 설정은 건드리지 않습니다. 대화 기록 파일을 읽기만 합니다.

알려진 한계

  • 브로드캐스트는 같은 서브넷에서만 닿습니다. 층이나 VLAN이 달라서 안 보이면 설정 → 내 프로필 → 고급: 자동으로 안 보일 때에 상대 IP를 넣어 주세요.
  • 공개 오피스는 앱을 설치한 사람이면 누구나 들어올 수 있습니다. 들어올 사람을 정하고 싶으면 팀 오피스를 쓰세요. 관리자가 문제 있는 사람을 내보낼 수는 있지만, PC 식별자로 막는 거라 profile.json을 지우면 다시 들어올 수 있습니다.
  • 회사 프록시나 방화벽이 바깥 wss(443) 연결을 막으면 다른 망 접속자가 목록에 안 나오고 "인터넷 연결 안 됨"이 뜹니다. 같은 망 PC는 그대로 보입니다. 억지로 우회하지 말고 IT 담당자에게 예외를 요청하세요.
  • 무료 서버라 동시 접속은 1,000명까지고, 하루 사용량이 한도의 95%에 닿으면 그날은 중계가 멈춥니다. 같은 망은 계속 되고, 한국 시간 오전 9시에 풀립니다.
  • 중계 위의 이름은 확인하지 않습니다. 누가 다른 PC의 식별자와 키를 베끼면 목록에 그 이름으로 나오거나 그 PC를 중계에서 밀어낼 수 있습니다. 사무실 내용은 같은 망에서 암호화돼 오가므로 보이지 않습니다.
  • 자리 공유는 같은 레이아웃끼리만 맞습니다. 두 PC가 같은 자리를 잡으면 한쪽이 양보하므로 잠깐 자리를 옮기는 모습이 보일 수 있습니다.
  • Codex는 승인 요청을 기록에 남기지 않아서, Codex의 빨간 !는 Codex가 질문할 때만 뜹니다.
  • 명령이나 검색어에 비밀번호를 직접 적었다면 가리지 못할 수도 있습니다.
  • 예전 버전 PC에는 일부가 안 보일 수 있습니다(0.4.x는 에이전트가 아주 많은 PC와 펫, 1.0.0 이하는 사람 캐릭터와 상태 메시지, 1.0.13 이하는 공유 레이아웃, 1.0.63 이하는 옷장, 1.0.64 이하는 세션 제목·토큰·자리 공유). 다 같이 업데이트하는 게 제일 좋습니다. 1.0.24 이하 PC와 개인용 PC는 서로 접속자 목록에 안 나올 수 있고, 1.0.63 이하 PC는 중계에 연결되지 않아(같은 망은 그대로) 접속자 목록 칩에 "퇴장"으로 나옵니다.
  • Mac 알림은 "Script Editor" 이름으로 뜰 수 있습니다. Linux와 WSL에는 트레이와 알림이 없습니다.
