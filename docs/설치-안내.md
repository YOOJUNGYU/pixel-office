# Pixel Office 설치 안내

> English: [INSTALL.en.md](INSTALL.en.md)

Pixel Office 는 앱을 설치한 PC 들의 코딩 에이전트(Claude Code·Codex)를 한 픽셀 사무실에 캐릭터로 보여 줍니다. 처음에는 혼자 쓰는 개인용으로 시작하고, 같은 망은 물론 다른 망(집·회사·카페)의 PC 도 인터넷 중계로 모이는 공개 오피스나 같은 망 팀원끼리만 쓰는 팀 오피스로 언제든 바꿀 수 있습니다(4-1). 다음에 켜면 마지막에 고른 오피스로 열립니다. **각 PC 에 한 번씩 설치**하면 로그인할 때 자동으로 켜지고, 다른 PC 를 저절로 찾습니다. Node 같은 다른 프로그램은 따로 설치할 필요가 없습니다.

## 1. 내려받기

[GitHub Releases](https://github.com/YOOJUNGYU/pixel-office/releases/latest) 에서 내 PC 에 맞는 파일을 받습니다.

| PC                         | 파일                             |
| -------------------------- | -------------------------------- |
| Windows 10/11 (64비트)     | `PixelOffice-<버전>-Windows.exe` |
| Mac (Apple 칩, Intel 모두) | `PixelOffice-<버전>-Mac.pkg`     |

Mac 파일은 하나라서 칩 종류를 확인할 필요가 없습니다.

## 2. Windows 에 설치

1. 받은 `PixelOffice-<버전>-Windows.exe` 를 실행합니다.
2. **"Windows의 PC 보호"** (SmartScreen) 창이 뜨면 **추가 정보** → **실행** 을 누릅니다. 설치 파일에 코드 서명이 없어서 뜨는 창입니다.
   _(스크린샷 자리: SmartScreen 추가 정보 → 실행)_
3. **사용자 계정 컨트롤**(UAC) 창에서 **예** 를 누릅니다. 관리자 권한은 프로그램 폴더 설치와 Windows 방화벽 규칙("Pixel Office") 추가에만 쓰입니다.
   _(스크린샷 자리: UAC 승인)_
4. **추가 작업 선택** 화면의 두 항목은 기본으로 체크되어 있습니다. 필요 없으면 풀고 진행합니다.
   - **바탕화면에 바로가기 만들기**
   - **로그인할 때 자동으로 실행** (지금 사용자 계정의 시작프로그램에 등록. 나중에 사무실 **설정** 에서도 바꿀 수 있습니다)
5. 설치 마법사를 끝까지 진행하면 브라우저에 사무실이 열립니다. 캐릭터·색만 고르면 끝입니다(닉네임은 선택, 이름은 PC 계정 이름으로 표시).

## 3. Mac 에 설치

1. 받은 `.pkg` 파일을 더블클릭합니다.
2. Apple 공증을 받지 않은 설치 파일이라 처음에는 막힙니다. **"'PixelOffice-<버전>-Mac.pkg'을(를) 열지 않음"**(macOS 15 이상) 또는 **"확인되지 않은 개발자"** 창이 뜨면:
   1. **완료**(또는 **확인**)를 누릅니다. **휴지통으로 이동** 은 누르지 마세요.
   2. **시스템 설정 → 개인정보 보호 및 보안** 을 열고 아래로 내려 "…Mac.pkg 의 사용이 차단되었습니다" 옆 **그래도 열기** 를 누릅니다(관리자 암호). 이 버튼은 막힌 뒤 1시간쯤만 보이니, 없으면 pkg 를 한 번 더 열었다가 다시 확인합니다.
   3. pkg 를 다시 열고 **열기** → 설치를 진행합니다(관리자 암호 입력).
   - 터미널로 설치해도 됩니다(이 검사를 거치지 않음): `sudo installer -pkg ~/Downloads/PixelOffice-<버전>-Mac.pkg -target /`
   - 회사가 관리하는 Mac 에서 **그래도 열기** 가 없거나 계속 막히면 관리 정책(MDM) 때문입니다. 우회하지 말고 IT 담당자에게 요청하세요.
     _(스크린샷 자리: 개인정보 보호 및 보안 → 그래도 열기)_
3. 설치가 끝나면 사무실이 백그라운드에서 켜집니다. **"node" 가 들어오는 네트워크 연결을 허용하겠습니까?** 창이 뜨면 **허용** 을 누릅니다. 허용하지 않으면 다른 PC 에 내 에이전트가 보이지 않습니다.
   _(스크린샷 자리: macOS 방화벽 들어오는 연결 허용)_
4. **응용 프로그램 → Pixel Office** 를 열면 브라우저에 사무실이 열립니다 (`http://localhost:47801`).

로그인할 때마다 자동으로 켜집니다 (`~/Library/LaunchAgents/com.pixeloffice.agent.plist`, 사무실 **설정** 에서 끌 수 있음). 기록은 `~/Library/Logs/PixelOffice.log` 에 남습니다.

## 4. 실행 방법

- **로그인할 때 자동 실행**: 창 없이 백그라운드에서 켜집니다. 끄거나 다시 켜려면 사무실 화면 **설정 → 로그인할 때 자동 실행** 을 누릅니다 (다음 로그인부터 적용, 지금 켜진 사무실은 그대로). 업데이트를 설치해도 이 선택은 유지됩니다.
- **트레이 아이콘 · 완전 종료**: 켜져 있는 동안 Windows 는 작업 표시줄 알림 영역(트레이, 안 보이면 **^** 안), Mac 은 메뉴 막대에 Pixel Office 아이콘이 있습니다. 클릭(Windows 는 왼쪽 클릭으로 바로 열림) → **Pixel Office 열기** / **Pixel Office 종료**. 종료하면 다른 PC 에서도 내 PC 가 사라지고, 다음 로그인(자동 실행이 켜져 있으면) 또는 바로가기·앱으로 다시 켤 때까지 꺼져 있습니다. 아이콘이 안 보이면 사무실 **설정 → 완전 종료** 로도 끌 수 있습니다 (열려 있던 창에는 "종료했습니다" 가 표시됩니다).
- **업데이트**: 앱을 켤 때와 6시간마다 새 버전을 확인해 **자동으로 조용히** 업데이트합니다(관리자 암호·설치 창 없음). 열려 있던 창은 새 버전으로 스스로 다시 열리고 "v1.0.2 로 업데이트됨" 이 잠깐 뜹니다. 자동 업데이트는 끌 수 없습니다. 단, **1.0.0 설치 파일은 한 번 직접 설치**해야 하고, 그 뒤에는 Node 런타임이 바뀌는 릴리스만 화면 오른쪽 위 **업데이트** 버튼(설치 파일)으로 설치합니다. 릴리스의 `…-app.tgz` / `.sha256` 파일은 자동 업데이트용이니 직접 받지 마세요.
- **PC 알림**: 공개 오피스에 누가 들어오거나 나가면, 그리고 내 PC 의 Claude·Codex 에이전트가 응답을 기다리거나 작업을 마치면 Windows/Mac 알림으로 알려 줍니다(창을 닫아 둬도 트레이 아이콘이 있으면 옵니다). 보고 있는 오피스에 누가 새 채팅 말풍선을 올려도 알려 줍니다. **설정 → 접속·퇴장 알림 / 내 에이전트 알림 / 채팅 알림** 으로 따로 끌 수 있습니다. Windows 에서는 "Pixel Office" 이름과 아이콘으로 뜹니다(설정 → 시스템 → 알림 에 "Pixel Office" 항목이 생깁니다). 처음에 Windows·Mac 이 알림 허용을 물어볼 수 있으니 허용해 주세요. Mac 에서는 알림이 "Script Editor" 또는 "osascript" 이름으로 보일 수 있습니다(시스템 설정 → 알림 에서 그 항목을 켜 두세요). Windows 에서 집중 지원(방해 금지)이 켜져 있으면 알림 센터에만 쌓입니다.
- **사무실 열기**
  - Windows: 바탕화면의 **Pixel Office** 바로가기, 또는 시작 메뉴 → **Pixel Office 열기**
  - Mac: **응용 프로그램** 폴더나 **Launchpad** 의 **Pixel Office**. Mac 은 관례대로 바탕화면 바로가기를 만들지 않습니다 (Dock 에 끌어다 두면 편합니다).
  - 어느 PC 든 그 PC 의 브라우저에서 `http://localhost:47801` (화면은 내 PC 에서만 열립니다. 다른 PC 브라우저로는 볼 수 없습니다)
- Windows 바로가기는 사무실이 꺼져 있으면 켜고, 다음 순서로 엽니다: **앱으로 설치한 Pixel Office**(Edge, 없으면 Chrome) → Edge(또는 Chrome) 새 창(여기서 앱 설치 창이 뜸) → 기본 브라우저. Mac 은 기본 브라우저로 엽니다.
- 처음 열면 화면 기능을 하나씩 짚어 주는 안내가 나옵니다. 언제든 **설정 → 사용법 다시 보기** 로 다시 볼 수 있습니다.

### 앱으로 설치 (PWA)

내 PC 브라우저에서 사무실을 열면 오른쪽 위에 **Pixel Office 를 앱으로 설치하세요** 창이 뜹니다.

- **Edge·Chrome**: **설치** → 브라우저의 설치 확인 창에서 **설치**. 이후 Windows 바로가기와 시작 메뉴가 탭 없는 앱 창으로 엽니다(Mac 은 기본 브라우저). 주소창 오른쪽의 앱 설치 아이콘으로 설치해도 됩니다.
- **Safari**: **공유 → Dock에 추가**(Mac) / **홈 화면에 추가**(iPhone·iPad)
- **Firefox**: 앱 설치를 지원하지 않습니다. Edge 나 Chrome 으로 여세요.
- **나중에** 를 누르면 7일 동안 다시 묻지 않습니다. 앱 창 안이나 설치를 마친 뒤에는 뜨지 않습니다.
- **PWA 만 실행했는데 서버가 꺼져 있으면**: "Pixel Office 서버가 꺼져 있습니다" 와 큰 **[시작]** 버튼이 뜹니다. 누르면 브라우저가 **"Pixel Office 열기"** 를 묻습니다 → 허용(**항상 허용**에 체크하면 다음부터 묻지 않음). 서버가 켜지면 창이 저절로 사무실로 바뀝니다. 20초가 지나도 안 켜지면 시작 메뉴(Mac 은 응용 프로그램)의 Pixel Office 로 실행하세요. 종료한 뒤 남아 있는 창에도 같은 [시작] 이 뜹니다.
  - [시작] 은 설치 프로그램이 등록하는 `pixeloffice:` 주소를 씁니다. **이 기능이 들어간 설치 프로그램으로 한 번 다시 설치해야** 동작합니다(앱 안 자동 업데이트로는 등록되지 않음). 이 주소는 늘 같은 실행 명령만 돌리고 주소 내용은 전혀 넘기지 않습니다.
- 앱을 지우려면 Edge 는 `edge://apps`, Chrome 은 `chrome://apps` 에서 Pixel Office 를 제거합니다. 바로가기는 다시 Edge(또는 Chrome) 새 창으로 엽니다.

## 4-1. 공개 오피스 · 팀 오피스 · 개인용

- 처음 설치하면 🏠 **개인용**으로 시작합니다. 위쪽 탭(🏠 개인용 · 🌐 공개 오피스 · 🔒 팀)으로 바꾸면 다음에도 마지막에 고른 오피스로 열립니다. 앱 설치자가 모두 모이는 곳은 🌐 **공개 오피스**입니다. **어느 망에서든**(집·회사·카페) 앱만 설치하면 같은 공개 오피스에 들어옵니다. 같은 망 PC 는 바로, 다른 망 PC 는 Cloudflare 중계를 거쳐 보입니다(Pixel Office 외에 설치할 것은 없고, 나가는 `wss` 443 연결 하나만 씁니다). 설정할 것이 없고 업데이트하면 자동으로 연결됩니다. PC 끼리 주고받는 상태는 자동으로 암호화됩니다(PC 마다 X25519 키, 두 PC 사이 키로 AES-256-GCM). 중계는 암호화된 내용을 전달만 합니다.
- **공개 오피스의 모든 사람**에게 내 계정 이름·별명·캐릭터·채팅·에이전트의 방과 활동 종류가 보입니다(내 에이전트의 파일·명령 같은 작업 내용은 안 나갑니다: 다른 사람의 에이전트는 어디서 왔든 말풍선 없는 조용한 모습으로만 보이고, 내 에이전트는 내 화면에서 그대로 자세히 보입니다). 팀 오피스에서는 팀원의 에이전트 작업 내용이 그대로 보입니다. 아바타 위치와 걷는 모습도 공개 오피스의 모든 사람에게 보입니다. 중계는 접속 IP 를 저장하지 않지만(같은 망 배지용 해시 태그만), 중계를 호스팅하는 Cloudflare 에는 각 PC 의 접속 IP 주소가 보입니다. 팀 오피스와 개인용은 인터넷으로 나가지 않습니다(팀 오피스는 같은 망 전용). 단, 대기실 오락실의 점수 기록만은 어느 오피스에서든 중계 서버(`wss`/`https` 443)에 PC 식별자와 표시 이름을 보내 저장합니다.
- **연결 상태 칩**: 공개 오피스 화면의 사람 패널 제목 옆에 뜹니다.
  - `🌐 인터넷 연결됨`: 정상.
  - `인터넷 연결 중…`: 접속하는 중.
  - `인터넷 연결 대기: 만원`: 중계 동시 접속 20명이 찼습니다. 5분쯤 뒤 다시 시도합니다.
  - `인터넷 연결 중단: 오늘 한도 소진`: 무료 서버 하루 한도의 95% 를 써서 그날은 멈춥니다(한국 시간 오전 9시 초기화 뒤 자동 재접속).
  - `관리자에 의해 퇴장`: 관리자가 나를 내보냈습니다(표시된 시각 뒤 다시 연결).
  - `인터넷 연결 안 됨 — 같은 망만 보임`: 인터넷에 못 닿습니다(오프라인, 회사 프록시·방화벽이 443 `wss` 를 막는 경우 등). 같은 망 PC 는 그대로 보입니다. 회사 프록시 환경에서는 연결이 안 될 수 있으니, 우회하지 말고 IT 담당자에게 예외를 요청하세요.
  - 어느 경우에도 **공개 오피스에 그대로 머뭅니다**(개인용으로 바뀌지 않음). 조건이 풀리면 저절로 다시 연결됩니다.
- **같은 망 배지**: 서로 다른 망의 사람이 둘 이상 보일 때만, 사람 패널에서 같은 망 사람끼리 같은 `망 1`·`망 2` 배지가 붙습니다(내 망 = 1). 회사가 출구 IP 를 여러 개 쓰면 같은 회사가 다른 번호로 보일 수 있습니다.
- **연결 경로 배지**: 공개 오피스의 다른 사람 줄마다 `LAN`(같은 망, UDP 로 직접 연결) 또는 `인터넷`(인터넷 중계 서버로 연결) 배지가 붙습니다. 망 개수와 상관없이 늘 보이며, 내 줄에는 없습니다.
- 공유 레이아웃도 인터넷으로 주고받습니다. 공개 오피스의 누구나 편집·저장할 수 있고 마지막 저장이 이깁니다.
- 🔒 **팀 오피스 만들기**(팀은 한 번에 하나만: 새로 만들거나 참여하면 확인 후 지금 팀이 바뀝니다): **설정 → 오피스 → 팀 오피스 만들기** 에 팀 이름을 적고 **만들기** → 나온 초대 코드(`PO2-…`)를 **코드 복사** 해서 팀원에게 메신저로 보냅니다.
- **참여**: **설정 → 오피스 → 코드로 참여** 에 코드를 붙이고 **참여**. 화면 위의 오피스 버튼으로 오피스를 오갑니다.
- **팀 오피스에 들어가 있으면 공개 오피스에서 빠집니다**(에이전트·채팅은 보내지도 보지도 않음). 공개 오피스로 돌아가려면 **내 팀 오피스** 에서 **나가기** 합니다. 오른쪽 사람 패널에는 공개·팀·개인용 세 영역의 이름이 모두 보입니다.
- 팀 오피스 내용은 초대 코드로 만든 키로 암호화됩니다. 코드가 새면 새 팀 오피스를 만들어 옮기세요.
- 🏠 **개인용**: 맨 위 오피스 버튼의 **개인용**을 누르면 혼자 쓰는 작은 사무실로 바뀝니다(이름 카드 — 계정·별명·모습 — 만 다른 PC 의 사람 패널 `개인용` 영역에 보이고, 에이전트·채팅·캐릭터 위치는 나가지 않습니다). 팀 오피스는 그대로 남아, **공개 오피스**나 팀 버튼을 누르면 코드 없이 돌아갑니다. 개인용 사무실 배치는 이 PC 에만 따로 저장됩니다(공개·팀 오피스 배치는 그 오피스의 모두가 함께 씁니다).
- **관리자 강퇴(관리자만)**: 중계 관리자 토큰(`ADMIN_TOKEN`, 배포한 사람만 압니다)이 있으면 **설정 → 관리자 토큰** 에 넣고(이 PC 의 설정 파일에만 저장, 화면에는 다시 보이지 않음) 사람 패널의 공개 오피스 행 **[강퇴]** 로 내보냅니다. 앱 없이 curl 로도 됩니다(기본 24시간 차단, 시간은 `hours`):
  ```bash
  R=https://pixel-office-relay.pixel-office-relay.workers.dev   # 배포된 중계 서버 (relay/README.md)
  T='Authorization: Bearer <ADMIN_TOKEN>'
  curl -s -H "$T" $R/admin/stats                                          # 접속자·오늘 사용량
  curl -s -H "$T" -X POST -d '{"id":"<peerId>","hours":24}' $R/admin/kick # 강퇴
  curl -s -H "$T" $R/admin/bans                                           # 차단 목록
  curl -s -H "$T" -X DELETE $R/admin/bans/<peerId>                        # 해제
  ```
  차단은 PC 식별자 기준이라 `profile.json` 을 지우면 새 식별자로 피할 수 있습니다. IP 차단은 하지 않습니다(사내 전원이 같은 IP). 짧은 시간에 프레임을 쏟아내는 비정상 접속은 중계가 1시간 자동 차단합니다.
- **알려진 한계**: 중계 운영자가 악의적이면 처음 만나는 PC 쌍의 공개 키를 바꿔치기해 그 쌍의 내용을 읽을 수 있습니다(운영자 = 관리자). 키 지문 비교 화면은 아직 없습니다.
- 앱 없이 다른 PC 브라우저로 구경하는 기능(원격 구경)은 v0.4.0 에서 없앴습니다. 보려면 그 PC 에도 앱을 설치하세요.
- 1.0.24 이하 버전과는 사람 패널에서 서로 안 보일 수 있습니다(팀·개인용 PC 의 이름 표시).
- 1.0.13 이하 버전과 섞어 쓸 때: 공개·팀 오피스의 공유 레이아웃을 주고받지 못해, 그 PC 는 자기 기본 배치를 봅니다. 모든 PC 를 업데이트하세요.
- 1.0.0 이하 버전과 섞어 쓸 때: 1.0.0 이하 PC 에는 사람 캐릭터(방향키로 움직이는 내 캐릭터)와 채팅 말풍선이 보이지 않습니다. 모든 PC 를 업데이트하세요.
- v0.4.x 이후 버전과 섞어 쓸 때: 에이전트가 많은 PC 는 이제 상태를 여러 개의 작은 패킷으로 나눠 보내는데 v0.4.x 는 이를 읽지 못해, 그런 PC 는 v0.4.x PC 화면에 보이지 않습니다 (에이전트가 적은 PC 는 그대로 보임). 모든 PC 를 업데이트하세요.

## 5. 다른 PC 가 안 보일 때

- 인터넷으로 연결된 PC 는 위 **연결 상태 칩**이 `🌐 인터넷 연결됨` 일 때 망이 달라도 보입니다. 칩이 `인터넷 연결 안 됨` 이면 인터넷 쪽(회사 프록시·방화벽의 443 `wss` 차단 등)을 확인하세요.
- 같은 망의 PC 는 자동으로 보입니다. IP 를 적을 필요가 없습니다. 두 PC 가 **같은 네트워크**(같은 공유기·같은 사내망 대역)에 있어야 서로를 찾고, 게스트 Wi-Fi·VPN·다른 층 대역은 자동 탐색이 막혀 있을 수 있습니다.
- 다른 층이나 망에 있는 PC 만, 사무실 화면 **설정 → 내 프로필 → 고급: 자동으로 안 보일 때 → 직접 연결할 PC IP** 에 상대 PC 의 IP 를 한 줄에 하나씩 적고 저장합니다. 한쪽만 적어도 서로 보이지만, 상대 PC 도 내 IP 를 적어 두면 더 확실합니다.
  - Windows IP 확인: 명령 프롬프트에서 `ipconfig` → "IPv4 주소"
  - Mac IP 확인: 시스템 설정 → 네트워크 → 연결된 항목 → "IP 주소"
- **양쪽 모두 0.2.0 이상**인지 확인합니다. 0.2.0 은 암호화하지 않는 0.1.0 과 통신하지 않습니다.
- 둘 중 한 명이라도 **팀 오피스**나 🏠 **개인용**에 들어가 있으면 공개 오피스에서는 서로의 캐릭터·에이전트가 보이지 않습니다(팀 PC 의 사람 패널에는 공개 PC 이름이 보이지만, 공개 PC 에는 팀 PC 가 보이지 않습니다). 같은 팀 오피스에 들어가거나 둘 다 팀에서 나옵니다.
- 방화벽에서 UDP 47800 이 막혀 있지 않은지 확인합니다. Windows 는 설치기가 규칙(들어오는 UDP 47800)을 추가하고, Mac 은 3번의 "허용" 이 필요합니다. TCP 47801 은 내 PC 안에서만 쓰므로 열 필요가 없습니다.
- **회사 보안 솔루션**(백신·EDR·AppLocker·사내 방화벽 등)이 설치나 실행, 통신을 막으면 직접 우회하지 말고 IT 담당자에게 예외 등록을 요청하세요. 알려 줄 정보: 프로그램 위치(Windows `C:\Program Files\PixelOffice\node.exe`, Mac `/Applications/Pixel Office.app`), 포트 UDP 47800(들어오는 연결은 이것뿐, TCP 47801 화면은 내 PC 안에서만), 공개 오피스 중계로 나가는 `wss` 443 연결(Cloudflare Workers 주소, 들어오는 포트 없음).

다른 사람 PC 의 화면은 **읽기 전용**입니다. 다른 PC 에서 내 PC 의 무엇을 실행하거나 바꿀 수 없고, 내 화면에 접속할 수도 없습니다.

## 6. 제거

- **Windows**: 설정 → 앱 → 설치된 앱 → **Pixel Office** → 제거 (또는 설치 폴더의 `unins000.exe`). 실행 중인 사무실과 트레이 아이콘을 끄고, 설치 폴더(`C:\Program Files\PixelOffice`) 전체, 방화벽 규칙, 바로가기, 시작프로그램 등록, `pixeloffice:` 주소 등록을 지웁니다.
  - 마지막에 **"설정·레이아웃·사무실 정보까지 모두 삭제할까요?"** 를 묻습니다. **예** = 내 `%USERPROFILE%\.pixel-office` (프로필·키·팀 오피스 정보·레이아웃·받아 둔 업데이트)까지 삭제, **아니요**(기본) = 남겨 두어 다시 설치하면 그대로 이어서 씁니다. 조용한 제거(`/VERYSILENT`)는 묻지 않고 남겨 둡니다.
  - 제거는 관리자 권한으로 돌기 때문에, 다른 관리자 계정의 암호를 입력해 제거하면 지워지는 것은 **그 관리자 계정의** `.pixel-office` 입니다. 내 데이터를 지우려면 내 폴더의 `.pixel-office` 를 직접 지우세요.
- **Mac**: 터미널에서 아래를 실행합니다.

  ```bash
  curl -s -X POST http://127.0.0.1:47801/api/quit
  launchctl bootout gui/$(id -u)/com.pixeloffice.agent
  rm -f ~/Library/LaunchAgents/com.pixeloffice.agent.plist
  rm -f ~/.pixel-office/autostart-off   # '자동 실행 끔' 기록 (남아 있으면 다시 설치해도 자동 실행이 꺼진 채로 남음)
  /System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister -u "/Applications/Pixel Office.app"   # pixeloffice: 주소 등록 해제
  sudo rm -rf "/Applications/Pixel Office.app"
  sudo pkgutil --forget com.pixeloffice.pkg   # 설치 기록
  rm -f ~/Library/Logs/PixelOffice.log
  ```

  이 Mac 의 다른 계정에서도 설정으로 자동 실행을 켰다면, 그 계정으로 로그인해 `launchctl bootout …` 과 `rm -f ~/Library/LaunchAgents/…` 두 줄도 실행합니다.

내 설정·레이아웃(`~/.pixel-office/`)은 남겨 둡니다 (Windows 도 같음: 설정에서 자동 실행을 껐다면 그 기록 `autostart-off` 도 남아, 다시 설치할 때 **자동 실행 체크를 켜면** 다시 켜집니다). 완전히 지우려면 그 폴더도 삭제합니다.
